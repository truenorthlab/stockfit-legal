Ticker code

The four-digit number that identifies a listed company

In detail

Every company listed in Japan carries a four-digit code. Names can look alike but codes never overlap, so ordering or searching by number is the safer route. Ranges of numbers roughly follow industry, and codes containing letters have appeared in recent years. A code from a delisted company is not reused for some time.

Example

Toyota Motor is 7203 and Sony Group is 6758.
