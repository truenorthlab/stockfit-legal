Psychological line

The share of recent days on which the price rose

In detail

The psychological line shows, as a percentage, how many days in a recent period closed higher than the day before. A 12-day window is common; a run of up days pushes the figure up and a run of down days pulls it down. It counts days only, not the size of each move, so a tiny gain and a large one each count as one day.

Example

If 9 of the last 12 days closed higher, the psychological line reads 75%.
